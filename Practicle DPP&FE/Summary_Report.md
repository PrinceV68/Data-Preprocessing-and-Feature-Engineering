# Project Summary — Data Analysis, Cleaning & Feature Engineering

## Covered Topics

1. **Data Analysis** — data analysis, project planning, ML problem framing, tensors and tensor concepts.
2. **Data Import & Understanding** — Excel/CSV concepts, JSON, SQL, API, inspection and cleaning.
3. **EDA** — univariate, bivariate, multivariate analysis and Pandas Profiling concept.
4. **Data Cleaning** — Simple Imputer, most-frequent categorical imputation, missing indicators, random sample imputation, KNN and MICE.
5. **Outliers** — Z-score, IQR, percentile method and Winsorization.
6. **Feature Transformation & Construction** — mixed variables, date/time variables, Complete Case Analysis, categorical encoding, numerical binning, scaling, feature construction, FunctionTransformer, PowerTransformer and ColumnTransformer.

## Final Output

`Final Dataset/processed_customer_data.csv`

The notebook demonstrates the techniques with the supplied customer, transaction and product datasets and validates the final processed data before export.
